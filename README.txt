YouTube Converter

How to use:
1. Double-click the YouTube Converter shortcut.
2. Paste a YouTube link.
3. Check the preview to make sure it is the right video.
4. Choose MP3 or MP4.
5. Pick audio quality for MP3, or video resolution for MP4.
6. Press Convert.

The app saves files to Downloads by default.
MP3 and MP4 each remember their own last-used save folder.
You can edit the file name before pressing Convert; the correct extension is added automatically.
When a conversion finishes, the save folder opens automatically.

If YouTube asks you to sign in to confirm you are not a bot:
1. Sign in to YouTube in Brave, Chrome, Edge, Firefox, or Opera.
2. Choose that browser under Login fallback in the converter.
3. Approve local browser-session access, then try again.
The converter reads the browser cookies locally and does not save them.

The hidden app folder contains the converter's internal files and must stay
inside the YouTube Converter folder beside the YouTube Converter shortcut.
If YouTube changes something and conversions stop working, click Update Engine
at the top of the converter. The app updates its compatibility components,
checks that the engine is healthy, and restarts automatically.

Please use this only for videos you own, have permission to download, or that are licensed for downloading.

Windows may show a SmartScreen warning because this is a homemade app and not signed by a software company. If you trust the person who gave it to you, choose More info, then Run anyway.
